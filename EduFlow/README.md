# 🎓 EduFlow - Plataforma de Contenido Educativo de Pago

Una plataforma moderna y completa para vender tutoriales, cursos y contenido educativo con suscripción recurrente.

## ✨ Características

✅ Creadores suben videos y fijan precios  
✅ Estudiantes compran suscripción mensual/anual  
✅ Admin controla precios y métodos de pago  
✅ Pagos: Stripe, Yape, Transferencias bancarias  
✅ Dashboard en tiempo real  

## 🚀 Instalación Rápida

```bash
cd EduFlow
docker-compose up --build
```

- Frontend: http://localhost:3000
- Backend: http://localhost:5000

## 📚 Stack
- Frontend: Next.js + React + Tailwind
- Backend: Node.js + Express + MongoDB
- DevOps: Docker
